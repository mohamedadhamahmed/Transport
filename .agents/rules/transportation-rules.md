# قواعد ومحددات مشروع إدارة النقليات

## 1. بيئة التشغيل
- السيرفر المحلي: XAMPP على نظام Windows.
- مترجم PHP المعتمد لأي أمر أو سكريبت: `C:\xampp\php\php.exe`.
- قاعدة البيانات: MySQL `transportation`.

## 2. موديول الشاحنات والصيانة وأذونات الصرف
- **صيانة الشاحنة**: يمكن نقل الشاحنة لوضع الصيانة (`maintenance`) وإرجاعها بزر نقرة واحدة `toggle-maintenance`.
- **عدادات الزيت**:
  - يتم تسجيل القراءة الحالية `current_odometer` وحساب قراءة الغيار القادمة `next_oil_change_odometer` حسب الفترات الدورية (4,000 / 5,000 / 10,000 كم).
  - لوحة متابعة الشاحنات تعرض شارات ملونة تنبه باقتراب أو استحقاق موعد غيار الزيت.
- **إذن صرف قطع الغيار والزيوت (`TruckStoreIssue`)**:
  - صرف أصناف من المستودع لصالح شاحنة معينة.
  - خصم الكميات المنصرفة فورياً من رصيد الصنف `products.stock_quantity`.
  - القيد المحاسبي: قيد استهلاك مخزني (مدين: مصروف صيانة الشاحنة بمركز تكلفتها، دائن: المخزون السلعي 181).
  - **لا يمس الخزينة أو البنك نهائياً**.

## 3. المعايير المالية والبرمجية
- جدول الحسابات الرئيسي هو `financialaccount`.
- تحديث الأرصدة المالية يتم دوماً عبر `AccountEffect::apply()` وعكسها عند الحذف أو التعديل عبر `AccountEffect::reverse()`.
- كافة العمليات المالية المتعددة يجب أن تكون داخل `DB::transaction(...)`.
- التخاطب وواجهات المستخدم ورسائل النظام باللغة العربية.
